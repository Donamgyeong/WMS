# 근로시간 계산 엔진 테스트 보고서

검증일: 2026-11-13 (Asia/Seoul)

## 구현 범위

수락 이벤트에서 실제 근무·휴게 구간을 재생하고 누적 근로시간·야간·자정 경계를 분할한다. 일·주·월 집계, 본인/담당 부서/관리자 조회, 관리자 종료 세션 재계산, 파생 버전·원본 근거 보존을 포함한다. 계산 계약은 [결정 기록](decisions/0003-worktime-calculation.md)을 따른다.

## 최종 실행 결과

| Drizzle | 생성 SQL 검토·적용 성공 | 0006 SQL·메타데이터 보존 | `npm run db:generate`, `npm run db:migrate` |

총 97개 테스트를 통과했다. 이번 기능 테스트는 단위 19개·통합 15개·E2E 1개로 35개이며, 나머지는 기존 인증·근태·근무지·스키마 회귀 테스트다. 반복 실행 횟수를 테스트 개수에 더하지 않았다.

DB 테스트는 Docker PostgreSQL 17의 전용 `wms_auth_test`에서 수행했다. 통합/E2E를 동시에 실행하지 않았다. 0006은 테스트 DB와 현재 개발 DB에 적용했다. 운영 DB 검증은 수행하지 않았다.

## 데이터·동시성·버전 확인

- 재계산 시 새 세션·구간 및 이벤트/정책/일정/휴일/휴가/정정/엔진/옵션 스냅샷을 저장했다.
- 동일 재계산의 동시 2회 실행은 최초 생성 1회와 기존 결과 반환 1회로 끝났고 버전이 중복 생성되지 않았다.
- 입력 일정 변경 시 새 버전을 만들고 이전 구간을 보존했다. 조회는 최신 버전만 집계해 540분이 중복 합산되지 않았다.
- 정책 배정 변경 시 새 세션의 work_policy_id와 실제 입력 스냅샷의 정책 ID가 일치했다.
- 원본 이벤트의 기존 세션 FK는 유지했고 원본 UPDATE는 append-only 제약으로 거부됐다.
- 근로 구간 중복과 구간 생성 후 세션 근거 수정은 DB 제약으로 거부됐다.
- 범위 안에 열린 세션이 있으면 저장 재계산 전체가 롤백됐다. 열린 세션의 조회는 별도 잠정 결과를 제공했다.
- 승인 정정이 있으면 정정 반영 완료로 표시하지 않고 CORRECTION_REPLAY_PENDING 사유를 유지했다.
- 기존 스키마 통합 테스트로 확정 정산·라인·근거 보존 제약도 회귀 검증했다. 이번 기능이 정산을 새로 계산·확정하는 것은 아니다.

## 권한·API·브라우저 확인

- 비로그인 401, 비관리자 재계산 403, 직원 타인 조회 403, 부서장 타부서 조회 403을 확인했다.
- 담당 부서 조회는 허용하고 관리자 재계산은 허용했다.
- 잘못된 날짜/역전 기간/집계 기준/야간 종료/주 시작일/중복 파라미터/알 수 없는 필드를 400으로 거부했다.
- 관리자 POST의 외부 Origin은 403, JSON이 아닌 요청은 415로 거부했다.
- 조회·오류 응답의 no-store와 비관리자 응답의 임금 필드 비노출을 확인했다.
- 명시적인 주 시작일과 기간에 잘린 부분 주 표시를 확인했다. 경보 정책은 UNDECIDED로 남았다.
- 실제 브라우저 로그인→출근→잠정 조회→퇴근→관리자 재계산→동일 재계산 재시도→직원 최신 버전 조회→새로고침 후 원본 출퇴근 내역 유지 흐름을 통과했다.
- 기존 PC 기록·모바일 GPS·응답 유실 재시도, 로그인·초기 비밀번호·역할·로그아웃, 1440/390/320px 레이아웃, JavaScript 켜짐/꺼짐 인증 회귀가 통과했다.

## 검증 중 발견·해결한 사항

- `.next` 내부의 기존/재생성된 `* 2.ts` 캐시가 중복 타입 선언 오류를 일으켰다. 해당 생성 캐시를 `/tmp/wms-worktime-generated-types`로 분리한 뒤 타입 검사·빌드를 통과했다. 앱 소스나 tsconfig로 오류를 숨기지 않았다.
- 반복 통합 실행에서 이전 테스트의 휴일 캘린더가 남아 고정 ID 중복 오류가 발생했다. 새 통합 테스트의 beforeEach에서 전용 테스트 DB의 캘린더까지 초기화하도록 수정했다.
- Vite CommonJS 설정 및 NO_COLOR/FORCE_COLOR 경고는 비차단 경고다. 잘못된 비밀번호 테스트의 Better Auth 경고는 의도한 실패 입력에 대한 로그다.

## 남은 범위와 검증 한계

반차 휴게·연장 승인·휴일 가산·포괄 배정·정정 재생·급여 정산은 확정하지 않았다. 저장된 종료 세션 계산은 정책 변경만으로 자동 갱신되지 않으므로 명시적인 재계산이 필요하다. 주간 차트의 예시 데이터를 실제 집계로 교체하는 UI 작업은 포함하지 않는다. 운영 데이터량의 부하/성능, 운영 배포, 외부 휴가 동기화는 검증하지 않았다.
