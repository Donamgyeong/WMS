# 화면별 실제 데이터 연결 및 미구현 기능

확인일: 2026-11-13 (Asia/Seoul). 현재 코드 기준이며 근무정책을 변경하거나 미정 정책을 확정한 문서는 아니다.

## 연결 완료

| 화면 | 실제 조회·처리 기능 |
| --- | --- |
| 개인 대시보드 `/me` | 출퇴근·다중 휴게 기록, 현재 상태, 실근로시간, 주간 표시 범위 차트, 미종료 기록, 향후 일정 |
| 부서장 대시보드 `/team` | 담당 부서 재직자 현재 상태·주간 실근로·미종료 기록·승인 휴가·반차, 검색·부서 필터 |
| 관리자 대시보드 `/admin` | 전체 재직자·부서별 현황, 최근 저장된 정산 기간의 직원별 최신 계산 합계 |
| 부서원 근태 `/team/attendance` | 담당 부서의 기간·직원별 세션 및 일별 집계, 실근로·휴게·연장·야간·휴일, 미확정 사유, 기록 선택 |
| 부서원 근태 상세 `/team/attendance/detail` | 선택 직원·근무일의 원본 이벤트, 정정 이력, 계산 버전, 근로 구간, 관련 정책 |
| 전체 근태 `/admin/attendance` | 전체 직원의 근태 조회·상세, 종료 근무일의 기존 재계산 API 실행, 원본·이전 계산 버전 보존 |
| 조직·권한 `/admin/organization` | 활성·비활성 계정, 사번·소속·입퇴사일·역할·담당 부서, 부서 계층·지정 부서장·활성 인원 |
| 근무 설정 `/admin/settings` | 정책·버전·유효 기간·미정 항목, 근무지 GPS·등록 반경·허용 CIDR, 직원별 정책 적용 이력 |
| 부서 일정 `/team/calendar` | 담당 부서의 등록 근무일·휴무일, 휴가·반차 승인 상태, 유효 기간 내 배정 캘린더의 휴일 |
| 휴일·개인 일정 `/admin/calendar` | 등록 휴일·출처·캘린더·시간대, 직원별 근무·휴무, 휴가·반차 및 캘린더 배정 |
| 시급·계약 `/admin/contracts` | 전체 시급·계약 이력과 적용 기간, 조회 시작일 기준 유효 여부, 고정수당·포괄 포함시간·미정 정책 |
| 정산 목록·상세 `/admin/settlements` | 기간별 저장 정산, 직원별 최신 버전, 선택 계산의 근거·입력 스냅샷·이전 버전·별도 조정 이력 |

모든 관리 화면에서 예시 데이터와 작동하지 않는 예시 저장 버튼을 제거했다. 데이터가 없으면 빈 상태를 표시한다. 하위 관리 화면은 수동 기간 조회·재조회, 직원 선택 및 이름·내용 검색을 제공한다. 부서 필터는 직원과 연결된 행에 적용하며 공통 설정·정산 기간 등 공통 행은 유지한다. 표는 30행씩 페이지를 나눈다.

하위 관리 API: `GET /api/{team|admin}/management/{화면 key}`. `from` 포함, `to` 제외, 최대 366일. 선택 조건은 `employeeId`, `workDate`, `calculationId`다. 직원별 시급·계약 이력과 공통 정책은 전체 이력을 표시하며, 날짜 범위는 근태·일정·정산 기간에 적용한다.

부서장은 담당 부서만 조회한다. ADMIN 겸직이어도 `/team` 범위를 넓히지 않는다. 관리자 데이터는 관리자 API에서만 반환하고 비관리자에게 시급·계약·정산·임금 스냅샷을 제공하지 않는다. 근태 원본 조회에는 검증 결과를 표시하고 GPS·IP 검증 증거 원문은 전달하지 않는다.

## 미구현 — 외부 연동

- 다우오피스 휴가·반차 신청/승인 동기화. 현재 `leave_records`에 저장된 기록만 조회한다.
- 공휴일·대체공휴일 데이터 자동 수집·갱신. 현재 저장된 휴일만 조회한다.

## 정책 결정 후 구현할 항목

- 월 960분 포괄 포함시간의 일반·야간 배정 순서 및 고정수당과 실제 법정수당 비교 방식.
- 반차 휴게시간 및 4시간 초과분 연장 인정, 연장·정정 승인 절차.
- 휴일근로 배율·포괄 포함 여부, 주간 시작 요일·경보 기준, 야간 종료 시각, 반올림·세금·공제 범위.

미확정 값은 `NULL`/미확정으로 유지한다. 시급·계약 입력만으로 정산을 확정하지 않으며, 정산 금액이 없다는 이유로 0원으로 표시하지 않는다. 정책 결정과 서비스 구현은 별도 작업이다.

## 검증

- 단위: 관리 API의 날짜·기간·중복/허용 파라미터 검증.
- DB 통합: 전체 하위 화면, 담당 부서·겸직자 권한, 원본·정정·재계산 버전, 휴일 적용 기간, 조직·근무 설정, 시급 이력·정산 최신 버전·근거·조정 및 미확정 값.
- 브라우저: 전 경로 1440/1024/390/320px, 검색·기록 선택·상세 이동, 관리자 재계산, 저장된 정산 상세, 잘못된 조회 조건과 API 접근 차단.
